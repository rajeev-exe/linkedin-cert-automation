Privacy Policy

This application, LinkedIn Certificate Automation, is a personal developer project created by Rajeev Gandhi.

Information Used

The application may process LinkedIn authentication information required to authorize posting on behalf of the authenticated LinkedIn member.

Certificate Data

The application may process certificate documents supplied by the user in order to extract course names, skills, dates, and related information for generating professional LinkedIn content.

Data Storage

Authentication credentials and access tokens are stored locally and are not intentionally committed to the public source-code repository.

Third-Party Services

This application uses LinkedIn APIs to authenticate the user and publish authorized content.
